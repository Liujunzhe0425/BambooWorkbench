# 竹简工作台 v0.2.1 客户验收测试说明

适用对象：湖南桃花江竹材科技股份有限公司品质部。实施团队：湖南大学智创未来团队。

## 一、验收准备

- Windows 10/11 x64 测试电脑一台；
- `BambooWorkbench-Setup-0.2.1.exe` 与 `SHA256SUMS.txt`；
- 三类经脱敏的客户历史 Excel：竹丝水分、水煮实验、售后案件各不少于 3 份；
- 品质部业务负责人、实际操作人员和项目交接人员共同参加；
- 原始文件使用副本，现场记录人工期望结论，不直接覆盖生产文件。

## 二、通过标准

1. 安装、启动、关闭和卸载无终端黑框、崩溃或文件丢失；
2. 正常启动时三个真实模块均显示可用，不能显示为 Mock；
3. 每个模块能读取约定格式并生成可打开的 Excel/图表/报告；
4. 关键统计值与品质人员人工复算一致；
5. 异常标色、判定、复核项与已确认规则一致；
6. 证据不足、规则冲突或权限边界问题不会被 AI 擅自定案；
7. 任务历史、输入快照和输出可追溯，卸载不删除用户数据；
8. 若测试 DeepSeek，密钥不出现在数据库、输出和日志中，发送前必须人工确认。

任一关键规则计算错误、案件漏计/重复计、结果文件打不开、真实模块不可用或未经确认即联网，均判定本轮不通过。

## 三、执行用例

| 编号 | 场景 | 操作与核对 | 预期结果 |
|---|---|---|---|
| UAT-01 | 安装与图标 | 安装并检查开始菜单/桌面快捷方式 | 使用指定竹简工作台图标，启动不显示终端黑框 |
| UAT-02 | 默认真实模块 | 正常启动首页 | 三个模块可用且为真实模块；仅 `--demo` 使用模拟模块 |
| UAT-03 | 竹丝水分 | 导入含正常、偏低、偏高样本的历史副本 | 汇总、公式、标黄/标红和复核项与人工结果一致 |
| UAT-04 | 水煮实验 | 导入含正常、观察、不合格和冲突样本 | 密度、膨胀率、剥离判定及人工复核边界正确 |
| UAT-05 | 售后多标签 | 导入同时属于性能、外观、加工的案件 | 案件总数去重；同案可多标签；分类合计可大于案件数 |
| UAT-06 | 售后费用/状态 | 核对费用、采用方案、解决状态 | 只统计最终采用方案的明确费用；证据不足进入复核 |
| UAT-07 | 异常输入 | 导入空表、缺字段表和不支持文件 | 明确提示，不伪造结果，不影响其他任务 |
| UAT-08 | 历史追溯 | 完成任务后打开任务历史和输出 | 能定位输入副本、结果、时间和任务状态 |
| UAT-09 | DeepSeek 可选项 | 配置密钥并触发 AI 服务请求 | 显示脱敏预览；拒绝时不联网；同意后才发送 |
| UAT-10 | 卸载保留 | 创建任务后卸载并重新安装 | 用户数据保留，重新安装后仍可追溯 |

## 四、问题分级

- 阻断：无法安装/启动、真实模块缺失、数据损坏、未经确认联网；
- 严重：关键公式或统计口径错误、异常漏判、输出不可用；
- 一般：非关键文案、布局、提示或操作便利性问题；
- 建议：不影响当前落地的扩展需求。

阻断和严重问题必须整改并复验；一般问题由双方确认是否影响上线；建议项进入后续版本清单。
