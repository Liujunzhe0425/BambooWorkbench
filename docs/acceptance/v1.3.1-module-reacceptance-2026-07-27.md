## 水煮模块整改与重新交付说明

### 当前问题

使用已安装 v1.3.0 人工测试留下的 41 份真实输入执行最新源码 `finalize` 时，模块返回 `failed`，错误为：

`BOILING-SNAPSHOT-WRITE-001: 月度快照 payload 不得包含绝对路径`

### 问题位置和产生原因

问题位于 `modules/boiling/src/boiling_rollup.py` 的月度快照路径检测，以及 `modules/boiling/src/boiling_module.py` 的快照构造。

真实业务表中的部分字段使用单个 `/` 表示“无/未填写”。当前 `contains_absolute_path()` 将所有以 `/` 开头的字符串都识别为绝对路径，导致合法业务占位符被误判。已确认命中字段包括压制日期、浸胶日期、班组长和订单信息等业务字段；不涉及框架传入路径。

### 责任边界

这是水煮模块私有快照的数据规范化和验证问题。框架不得导入或修改水煮业务记录，也不能替模块猜测 `/` 的业务含义。

### 整改需求与必须达到的目标

1. 单个 `/` 等合法业务占位符不得被当作绝对路径。
2. 真正的 Windows、UNC 和 POSIX 绝对路径仍必须被拒绝，不能放宽快照的隐私与可移植性边界。
3. 使用本轮 41 份真实输入完成 `draft → confirmation → finalize` 后，结果状态必须为 `success` 或合同允许的 `partial_success`，且必须生成合法 `monthly_snapshot`。
4. 快照不得进入客户成果文件列表，不得包含源文件绝对路径、API 密钥或客户目录结构。

### 明确验收标准

- 新增回归测试：业务字段为单个 `/` 时，快照写入成功。
- 新增反向测试：`C:\\...`、`\\\\server\\share\\...`、`/home/...` 等真实绝对路径仍被拒绝。
- 新增或补充真实形态 finalize 合同测试，断言成功/部分成功结果必有快照。
- 水煮模块完整测试、Ruff、合同 CLI、源码自检全部通过。

### 修改范围限制与禁止事项

- 原则上只修改 `modules/boiling/`。
- 不修改 `core/`、`app/`、`packaging/`、`main` 或 `integration`。
- 不提交真实客户文件、生成成果、缓存、密钥或绝对路径。
- 不通过删除快照校验、允许任意路径或伪造成功状态规避问题。

## 水分模块整改与重新交付说明

### 当前问题

使用已安装 v1.3.0 人工测试留下的 21 份真实输入执行最新源码 `finalize` 时，模块进程退出码为 0，但结果为 `failed`，错误为：

`ARTIFACT_WRITE_FAILED: MONTHLY_SNAPSHOT_INVALID`

### 问题位置和产生原因

问题位于 `modules/moisture/src/moisture/application/monthly_snapshot.py` 的快照记录 ID 构造，以及 `modules/moisture/src/moisture/contract/monthly_snapshot.py` 的记录 ID 校验。

模块把 Excel 文件名去掉扩展名后直接作为 `record_id`。真实文件中存在扩展名前带空格的名称，因此产生尾随空格的业务记录 ID；新合同明确拒绝首尾空格，最终导致整套成果回滚。诊断结果为 21 条记录中 6 条 ID 带尾随空格，未发现重复 ID。

### 责任边界

这是水分模块的业务记录身份规范化问题。框架只消费模块生成的不可变快照，不能替模块修改文件名或业务记录 ID。

### 整改需求与必须达到的目标

1. 从源文件名或业务字段生成 `record_id` 时执行确定、可解释且稳定的规范化，至少移除首尾空白。
2. 规范化不得改变 Excel 内容、客户展示名称或业务公式。
3. 必须定义规范化后发生 ID 冲突时的确定性处理；不得静默覆盖记录。
4. 使用本轮 21 份真实输入 finalize 后，结果必须为 `success` 或合同允许的 `partial_success`，且必须生成合法 `monthly_snapshot`。
5. 快照仍须拒绝路径分隔符、控制字符、路径穿越和真正的不安全 ID。

### 明确验收标准

- 新增回归测试：扩展名前含空格、业务 ID 首尾含空白时，生成稳定且合同合法的记录 ID。
- 新增冲突测试：规范化后 ID 相同不得覆盖数据，须按模块确定的稳定方案处理或返回明确业务错误。
- 保留对 `/`、`\\`、控制字符、`..` 等不安全身份的拒绝测试。
- 新增或补充真实形态 finalize 合同测试，断言成功/部分成功结果必有快照。
- 水分模块完整测试、Ruff、合同 CLI、源码自检全部通过。
