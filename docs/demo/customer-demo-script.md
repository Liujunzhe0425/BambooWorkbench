# 竹简工作台空框架演示脚本（20 分钟）

对象：湖南桃花江竹材科技股份有限公司。演示团队：湖大智竹实践团队。

> 本次只演示统一框架和三个模拟模块。模拟输出不是企业质量判断，不能用于放行、责任或赔偿决定。

## 演示前检查（2 分钟）

- 使用安装版和打包内脱敏演示文件；
- 确认三张模块卡片均显示健康和版本；
- 确认 AI 提供商为“离线模拟”，不录入真实密钥；
- 清空演示用任务历史，不删除客户正式数据。

## 1. 统一入口与品牌（2 分钟）

展示竹简工作台、嫩竹绿色视觉、团队标志和湖南桃花江竹材科技股份有限公司使用场景。说明一个入口切换三类任务，模块内部算法由三位负责人分别交付。

## 2. 竹丝水分成功流程（3 分钟）

选择“竹丝水分”，导入普通脱敏 `.xlsx`，展示输入副本、进度、成功结果和历史记录；从结果中心打开模拟 Excel、图表、报告和结果目录。说明原文件没有被修改。

## 3. 水煮实验人工边界（3 分钟）

导入文件名带 `confirm` 的演示表，使任务进入“待确认”。展示原因、来源和建议，修改确认值后提交。说明正式结果来自 `phase=finalize` 再运行，框架不会替品质人员承担权限性判断。

## 4. 售后分析、知识和模拟AI（4 分钟）

先在知识库检索“售后”，说明正式规则优先于历史案例，当前只有确定性模拟检索。再运行售后 `ai` 场景，展示脱敏预览和授权记录；允许一次后查看模拟AI响应。强调模块拿不到 API 密钥。

再次运行并选择“拒绝联网”，展示服务响应状态为 `denied`，同时本地流程仍完成。说明真实 API 默认关闭，拒绝联网不影响基础处理。

## 5. 故障隔离和诊断（3 分钟）

运行 `fail` 或 `crash` 演示文件，展示模块失败被记录但主程序仍可切换页面和运行其他模块。打开任务历史、确认记录、日志目录、系统设置和本地数据目录；指出日志与数据库不保存 API 密钥。

## 6. 结论与反馈（3 分钟）

再次声明目前是空框架：三个真实模块的字段提取、公式、异常规则、Excel、图表和业务建议尚未接入。现场记录以下反馈：

- 操作是否清楚，重复录入是否足够少；
- 待确认问题是否符合品质人员工作边界；
- 结果、来源追溯和错误提示是否易懂；
- 是否接受本地保存和逐次联网授权；
- 三个业务模块还需哪些字段、图表或扩展。
