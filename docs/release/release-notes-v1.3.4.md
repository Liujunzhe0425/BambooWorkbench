# BambooWorkbench v1.3.4

发布日期：2026-07-28

## 本次修复

- 自动更新下载窗口实时显示百分比、已下载大小和总大小。
- 更新安装包及辅助程序改为暂存在系统临时目录，不再从即将被覆盖的安装目录运行。
- 覆盖安装显式使用当前应用所在目录，避免 Windows 缺少卸载注册信息时安装到默认目录。
- 安装后校验竹丝水分、水煮实验和售后分析三个模块均已更新到目标版本，成功后自动重启应用。
- 更新失败会写入独立辅助程序日志和 Inno Setup 日志，并尝试重新打开原有程序，便于排查。

本版本不改变三个业务模块的公式、阈值、规则或统计口径。v1.3.3 的售后日期与费用确定性识别修复继续保留。

## 更新方式

由于 v1.3.3 及更早版本的自动覆盖安装链路存在本次修复的问题，请从公开 Release 页面手动下载 v1.3.4 安装包，并覆盖安装到原目录。不要卸载或删除原安装目录。

完成这一次手动覆盖安装后，v1.3.4 及后续版本可以使用软件内的自动更新功能。覆盖更新会保留 source、output、数据库、任务快照、知识学习、模块数据、设置、安装实例标记和 Windows 凭据。
