# BambooWorkbench v1.3.0

发布日期：2026-07-26

## 本次更新

- 三个模块分别维护同年正式月度结果；允许月份缺口，并在替换或移除早期月份时原子重算已有后续月份。
- 新增“历史数据”页面，可按年份和模块查看十二个月状态并进入正式累计结果。
- 新增跨模块“待确认清单”和本地回答草稿，完成确认后进入生成进度并自动打开结果。
- 人工最终选择可以形成模块隔离、脱敏、可解释的偏好证据；用户可查看来源、撤销单任务证据或重置场景/模块。
- 安装根目录新增 `source` 和 `output`。默认 source 含三个模块子目录；每个任务的完整累计成果保存到独立结果目录。
- 成果目录包含隐藏只读任务清单；数据库丢失时可从清单恢复任务历史和月度索引。
- AI Provider 密钥和 GitHub 更新令牌支持分别删除；售后在全局配置已验证且未变化时跳过重复设置页。

## 安装与数据说明

建议从 v1.2.0 升级到 v1.3.0 时，在 Release 页面下载安装包并直接覆盖安装到原目录，不要先卸载或删除安装根目录。升级前建议备份 `source` 和 `output`。

首次安装不携带历史任务或 API Key。更新或原目录重装会保留 source、output、数据库、任务快照、知识学习、模块数据、设置、安装实例标记和 Windows 凭据。

## 安全边界

- 月度累计进程完全离线，只能读取框架复制到本次事务授权目录的只读快照。
- 框架复验快照大小、SHA-256、月份、模块和年份，并复算每个累计成果的 SHA-256。
- 偏好学习只影响人工确认建议值，不修改已批准规则、公式、阈值，也不会跳过人工确认。
- API Key、GitHub Token、客户原文和绝对路径不进入 Release 资产。
