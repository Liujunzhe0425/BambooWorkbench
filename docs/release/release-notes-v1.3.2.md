# BambooWorkbench v1.3.2

发布日期：2026-07-27

## 本次更新

- 售后投诉日期缺少年份或月份时，确认页不再预填不完整日期；用户必须明确填写 `YYYY-MM-DD`。
- 日期确认不能批量套用或记忆，框架 UI 和提交服务同时校验空值、格式和真实日历日期。
- DeepSeek 等在线 Provider 的读取超时调整为 90 秒；单批 AI 超时只形成降级警告，确定性处理和人工复核可以继续。
- 结果中心将 AI 降级与业务阻断错误分开显示，避免把网络波动误认为任务失败。
- 自动更新切换到公开二进制分发仓库，普通客户无需配置或持有 GitHub Token。

## 首次切换说明

v1.3.1 仍指向私有源码 Release，因此无令牌环境无法自动发现本版本。请从公开 Release 页面最后一次手动下载 v1.3.2 安装包，并覆盖安装到原目录。不要先卸载或删除安装根目录。

从 v1.3.2 开始，后续正式版本可以在不配置 GitHub Token 的情况下自动检测、提示、下载、校验和覆盖安装。旧版保存过的更新令牌不再使用，可在系统设置中删除。

## 数据与安全

覆盖安装保留 source、output、数据库、任务快照、知识学习、模块数据、设置、安装实例标记和 Windows 凭据。公开分发仓库不包含源码、客户数据、任务、日志、数据库或密钥。
