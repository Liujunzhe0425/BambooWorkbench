# BambooWorkbench v1.1.0

竹简工作台 v1.1.0 是客户首轮验收优化后的正式版本，产品与竹丝水分、水煮实验、售后分析三个业务模块统一为 `1.1.0`。

## 主要更新

- 竹丝水分：确定性四表汇总与独立 AI 辅助报告分离；普通报告聚合正常批次，只展开异常、失败和待复核项目。
- 水煮实验：存在确定性候选时通过工作台统一授权请求 AI 辅助说明；拒绝、断网或服务异常时继续输出完整离线成果。
- 售后分析：增加 Word 分析报告、品牌/原因/费用图表和逐年可视化看板，保留逐案人工复核和多标签统计。
- 框架体验：改进确认事项说明、失败文件明细、结构化成果阅读、输出目录、返回导航和任务完成状态。
- 安全边界：API Key 继续保存在 Windows 安全凭据中；联网前必须展示脱敏预览并由用户逐次授权。

## 下载

- `BambooWorkbench-Setup-1.1.0.exe`：Windows 每用户安装包。
- `BambooWorkbench-Portable-1.1.0.zip`：免安装便携包。
- `SHA256SUMS.txt`：发布文件 SHA-256 校验值。

Windows 10/11 用户建议使用安装包。覆盖安装会保留 `%LOCALAPPDATA%\BambooWorkbench` 中的本地任务、设置和历史数据。

## 验证结果

- 三个模块完整回归通过：水分 417 项、水煮 46 项、售后 51 项（另有 3 项按设计跳过）。
- 根框架测试通过：357 项（另有 8 项因当前 Windows 会话无符号链接权限而跳过）。
- 三个模块合同、版本、自检、Ruff、真实模块发现及正常/演示模式烟雾测试通过。
- 安装包经过静默安装、真实模式与演示模式启动、卸载及本地数据保留验证。

## 责任边界

AI 只提供辅助分析、原因解释和复核建议，不改变确定性公式、阈值、结构化业务记录或人工确认结果。最终质量判断、处置和责任认定仍由有权限的品质人员完成。
