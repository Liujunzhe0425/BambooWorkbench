# BambooWorkbench v1.3.1

发布日期：2026-07-27

## 本次更新

- 修复竹丝水分任务创建页和知识库确定性检索在小窗状态下的布局裁切。
- 优化历史数据页面布局，十二个月卡片充分使用可用宽度，模块切换显示选中状态，年份选择至少覆盖至 2077。
- 修复框架对失败、部分成功和成功月度结果的快照状态判断，保留月度事务的原子提交边界。
- 修复水煮真实业务数据中 `/` 占位符导致月度快照写入失败的问题，同时继续拒绝真正的绝对路径。
- 修复水分源文件名尾随空格导致月度记录 ID 不合法的问题，并保留稳定冲突检测。
- 售后任务在 draft 阶段检查所属年月；零匹配安全终止，部分跨月先进入人工确认，且确认前不调用 AI。

## 安装与数据说明

可以从 v1.3.0 直接覆盖更新到 v1.3.1。请安装到原目录，不要先卸载、删除安装根目录或删除 `source`、`output`。

覆盖更新会保留 source、output、数据库、任务快照、知识学习、模块数据、设置、安装实例标记和 Windows 凭据。首次安装不携带历史任务、客户文件、API Key 或 GitHub Token。

由于源码仓库当前为私有仓库，未配置只读更新令牌的测试机器应从 Release 页面手动下载安装包。任何安装包都不会内置仓库令牌。
