# BambooWorkbench v1.2.0

发布日期：2026-07-25

## 本次更新

- 竹丝水分：新增历史标准汇总追加、经验草稿/已批准/历史管理、规则草稿/当前/历史管理，以及任务创建时的规则版本与 SHA-256 快照。
- 水煮实验：完善 AI 辅助建议和人工开裂检查流程，保持确定性公式、阈值和业务记录优先。
- 售后分析：进入模块先完成框架托管的 AI 配置与连接验证；批次授权后先取得 AI 建议，再进行售后费用、责任工厂和投诉类型人工复核。
- 自动更新：Windows 安装版启动后异步检查最新正式 Release，经用户确认、安装包版本匹配和 SHA-256 校验后覆盖安装并自动重启。

## 安全边界

- API Key 只保存在 Windows 安全凭据管理器，不写入任务、SQLite、日志、输出、Git 或安装包。
- 三个模块进程均不直接访问外部 Provider；外部请求由框架统一授权、脱敏、调用和审计。
- AI 不发布水分经验或规则，也不替代水煮公式、售后费用、责任工厂、投诉类型及其他人工权限结论。
- 更新失败不影响三个本地业务模块继续运行。

## 下载与更新说明

首次安装请下载 `BambooWorkbench-Setup-1.2.0.exe`。便携使用可下载 `BambooWorkbench-Portable-1.2.0.zip`，并使用 `SHA256SUMS.txt` 校验文件完整性。

当前源码仓库是私有仓库。仓库协作者测试自动更新时，需要在应用中配置只拥有该仓库 `Contents: read` 权限的细粒度 GitHub Token；Token 不会内置在安装包中。向普通客户开放自动更新前，仍需配置独立的公开二进制仓库或 HTTPS/CDN 更新源。
