# BambooWorkbench v1.3.3

发布日期：2026-07-28

## 本次修复

- 售后原表提供完整投诉日期或合法 Excel 日期序列时直接采用，不再要求人工重复填写。
- 原表只提供月日、日期缺失或日期无效时仍要求填写完整 `YYYY-MM-DD`，不会用订单号或文件名猜测业务日期。
- 售后原表能够通过确定性规则识别唯一费用、明确总计或可验证算式时，直接写入结构化记录和最终成果，并标记为“自动识别”。
- 费用缺失、多个候选冲突、算式矛盾或只有 AI 候选时仍进入人工确认。
- 金额确认新增数值类型校验；日期、负数、NaN 和 Infinity 不再进入 finalize，避免任务因 `float(...)` 转换失败。

## 更新方式

v1.3.2 已使用公开二进制更新源，可直接在软件内手动检查更新，或等待启动后的自动更新提示。也可以从公开 Release 页面下载安装包覆盖安装。

覆盖更新保留 source、output、数据库、任务快照、知识学习、模块数据、设置、安装实例标记和 Windows 凭据。不要先卸载或删除原安装目录。
