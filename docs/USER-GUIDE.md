# 竹简工作台用户使用指南

本文档适用于 BambooWorkbench v1.3.5。完整的安装、目录、自动更新和开发说明见仓库根目录 [README](../README.md)。

## 1. 启动前准备

1. 建议将软件安装在非系统盘，例如 `D:\BambooWorkbench`；
2. 将待处理 Excel 放入安装目录下对应的 `source` 子目录，或保存在其他本地位置；
3. 确认年份、月份和输入文件属于同一个业务周期；
4. 如需售后 AI 辅助，在“系统设置”配置 Provider、HTTPS 地址、模型和 API Key，并完成连接测试。

## 2. 创建任务

在工作台选择竹丝水分、水煮实验或售后分析。创建页必须选择所属年份和月份，默认当前年月；任务名称默认采用“模块名—年份月份”，可以修改。

可以批量选择文件，也可以选择整个文件夹。选择文件夹时仅加入第一层受支持 Excel，不递归读取子文件夹。系统会忽略不支持或无效的文件，并在页面显示数量。

创建任务后，系统依次执行输入复制、确定性解析、规则判定、必要的 AI 服务请求和人工确认准备。不要在处理中移动安装目录或强制结束模块进程。

## 3. 待确认清单

左侧“待确认清单”只显示状态为“等待人工确认”的任务，跨三个模块按创建时间从新到旧排列。列表包含任务编号、模块、所属年月、创建时间和待确认数量。

点击任务进入确认页。每次修改都会自动保存本地草稿；返回清单或关闭软件后可以继续填写。草稿不参与知识学习。提交后进入生成进度页，任务完成后自动打开结果中心。

确认页默认允许将最终选择用于知识库更新，可按任务关闭。只有 finalize 成功并成为正式结果的任务才产生学习证据。

## 4. 结果中心与成果目录

任务的 Excel、分析报告、图表和结构化记录统一放在 `output` 下的任务文件夹中。结果中心可以直接打开所有可用成果。

如果成果文件被外部删除，任务记录会标记为“成果文件缺失”并禁止打开；用户可以选择重新生成成果或移除任务记录。

## 5. 历史数据

历史数据页左上角选择年份，中上方切换三个模块，下方显示该模块十二个月卡片：

- 未创建：灰色且不可点击；
- 已创建：可打开该月正式结果；
- 重算中：表示后续累计成果正在重新生成；
- 成果缺失：保留记录，但需要重新生成或移除。

三个模块彼此独立累计。新月份成果包含该年度此前已有正式月份的数据，不需要重复导入旧月份文件。

## 6. 知识库

知识库包含确定性检索资料和用户偏好证据。用户偏好按模块、稳定场景标识和脱敏上下文严格隔离，只调整以后确认页的建议排序。

可以查看权重及来源任务、撤销单条证据、重置学习场景或重置模块全部偏好。任何操作都不会修改已批准规则、公式或阈值。

## 7. 系统设置

系统设置提供：

- 默认输出位置；
- 默认是否允许 AI 联网；
- AI Provider、地址、模型与密钥；
- 删除当前 Provider 密钥；
- 自动检查更新开关与手动检查；
- 删除旧版 GitHub 更新令牌。

API Key 保存在 Windows 安全凭据管理器。删除密钥后，该 Provider 的连接验证状态同时失效。

## 8. 自动更新

发现新版本后，软件会显示当前版本和目标版本。确认下载后可查看实时进度；完成 SHA-256 校验后，软件退出、覆盖当前目录并自动重启。

若更新失败，重新打开软件不会影响现有任务和离线模块。可从本仓库 Releases 手动下载安装包覆盖原目录。

## 9. 常见检查

- 日期或任务年月冲突：返回创建页核对年月和输入文件；
- Excel 无法解析：确认文件未损坏、未加密并符合对应业务模板；
- AI 超时：检查网络、Provider 地址、模型和余额，确定性处理仍可继续；
- 结果无法打开：检查成果文件是否被移动、重命名或删除；
- 自动更新不可用：确认可以访问 GitHub，或从 Releases 手动下载安装。

业务公式、阈值和最终结论应由有权限的品质人员复核，AI 内容仅作为辅助信息。
