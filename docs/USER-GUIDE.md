# 竹简工作台 (BambooWorkbench) 使用说明

## 快速开始

1. 下载并安装 BambooWorkbench-Setup.exe
2. 双击桌面"竹简工作台"图标启动
3. 首次使用会显示三个业务模块卡片

## 三个业务模块

### 竹丝水分检测
- **功能**：读取批次竹丝水分测试 Excel，自动计算均值，按 47%—55% 标准判定是否异常
- **输入**：标准的竹丝水分检测 Excel 文件
- **输出**：结果 Excel（异常标红/标黄）+ Markdown 分析报告
- **异常规则**：水分 <47% 为偏低疑似，>55% 为偏高疑似，其余正常

### 水煮实验
- **功能**：解析水煮实验数据，判定密度、膨胀、剥离等指标
- **输入**：水煮实验记录 Excel
- **输出**：统计摘要 + 复核提示（严格密度规则与历史人工结论冲突时标记）
- **特殊处理**：信息不足的批次单独列出，不参与统计

### 售后分析
- **功能**：从售后案件 Excel 中提取关键字段，多标签分类
- **输入**：售后案件记录 Excel
- **输出**：分类汇总 Excel + 费用分析 + 图表
- **统计口径**：同一案件可进入多个分类（性能/外观/加工），案件总数去重计 1 次，分类合计允许大于案件总数

## 操作流程

1. 在工作台首页点击对应模块卡片
2. 点击"导入数据"选择 Excel 文件
3. 点击"开始分析"
4. 系统处理完成后弹出结果预览
5. 结果文件自动保存到 输出/ 目录

## 注意事项

- 所有数据保存在本地，不需要登录或联网
- 首次使用建议用小样本测试，确认结果符合预期
- 如遇异常提示，检查 Excel 格式是否与历史模板一致
