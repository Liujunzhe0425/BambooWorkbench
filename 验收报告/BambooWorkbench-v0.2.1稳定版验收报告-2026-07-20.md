## 一、验收范围

本轮针对 v0.2.0 合并后的完整仓库进行独立复核，并在 v0.2.1 稳定分支完成以下修复与验证：

- 恢复合并冲突中被误删的竹丝水分真实模块文件；
- 正式运行默认加载三个真实业务模块，`--demo` 才加载 Mock；
- 统一程序、安装包、构建脚本和发布元数据版本为 0.2.1；
- 修复 Windows PowerShell 5.1 下的干净环境启动验证；
- 增加 DeepSeek/OpenAI 兼容接口配置与运行时重载；
- 将团队名称统一为“湖南大学智创未来团队”；
- 对三类历史数据重新执行完整 draft、人工确认和 finalize 流程；
- 重新执行框架、模块、便携版、安装版与发布包验证。

## 三、自动化测试

- 仓库全量验证：框架测试 322 通过、8 跳过；模块测试 414 通过、3 跳过；Ruff、合同验证与工作树检查通过。
- 跳过项均为已识别的平台条件：Windows 当前账户缺少创建符号链接权限，以及售后模块按设计不提供独立 Web 服务。
- v0.2.1 定向回归：35 项通过，覆盖真实模块交付完整性、版本元数据、DeepSeek 提供方、设置热重载与主界面身份信息。

## 四、发布判定

本地源代码与历史数据验收已达到候选发布标准。最终发布仍须满足：

1. 便携版、安装版及干净环境启动验证全部通过；
2. `integration` 与 `main` 的 GitHub PR 检查绿色；
3. `v0.2.1` package 工作流成功；
4. Release 中的文件来自该工作流，并核对 SHA-256。

上述条件完成后，本报告结论更新为“可交付”。
