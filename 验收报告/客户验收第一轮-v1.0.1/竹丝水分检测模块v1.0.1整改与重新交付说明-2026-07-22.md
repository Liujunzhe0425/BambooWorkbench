# 竹丝水分检测模块 v1.0.1 整改与重新交付说明

日期：2026-07-22

对象：竹丝水分检测模块负责人

分支：`module/moisture`

允许修改目录：`modules/moisture/`

目标版本：`1.0.1`

## 一、责任边界

| 反馈 | 责任方 |
|---|---|
| `arrival_date/test_date` 中文化 | 框架方，水分负责人无需改字段合同 |
| AI 授权区大段脱敏 JSON 的展示 | 框架方，水分负责人不得删除安全预览或逐次授权 |
| 通用结构化 JSON 查看器 | 框架方；水分模块继续保证 JSON 合同正确 |
| 水分分析报告冗长、技术字段过多、不利于阅读 | 水分模块负责人 |
| 现有水分 AI 调用协议 | 已正常接入，水分负责人负责保持兼容并优化报告中的呈现 |

框架方不修改水分公式、阈值、筛查结果、Excel 内容或报告正文。

## 二、必须整改：重构水分分析报告

当前实测 `analysis_report.md` 约 182 行，对 21 个批次逐条输出正常与异常结果，保留长小数、规则快照、经验引用和降级技术字段。信息可追溯，但不适合作为客户快速复核报告。

以当前售后分析报告为表达基准，水分报告至少调整为：

1. **运行概况**：输入、成功、失败、待确认、规则版本；
2. **总体结论**：正常、偏高疑似、偏低疑似、区间值异常和 AI 复核数量；
3. **异常与待复核明细**：只列异常、失败和待确认批次，使用中文列名和百分比；
4. **AI 辅助复核**：明确哪些候选经过 AI、结果是否有效、是否降级；AI 不是质量结论；
5. **数据质量风险**：只列实际存在的问题，不输出大量空 warning 字段；
6. **建议的下一步**：给出可执行的复测、核对和人工确认建议；
7. **技术附录（可选）**：规则哈希、经验引用、全部正常批次等追溯信息放到末尾或独立文件。

具体要求：

- 正常批次不再逐文件占一段；可汇总数量，完整明细保留在 Excel/JSON；
- 水分率统一按百分比显示并控制合理小数位，不展示长 Decimal 原值；
- 区分“确定性规则初筛”“AI 辅助证据”“人工确认结论”，不得混称；
- 不直接输出 Python 字段名、空数组、`warnings` 对象或整段 JSON；
- 失败文件应显示文件名和简短公开原因；
- 报告必须声明不替代品质人员的放行、责任或处置决定。

## 三、保持现有 AI 接口兼容

水分模块已经按统一框架协议运行：草稿声明 `service_requests`，框架展示脱敏内容并逐次授权，框架调用 Provider，最终阶段从 `service_response_file` 读取响应，严格校验后应用，拒绝或失败时保留离线结果。

本轮不得：

- 在模块中直接读取 API Key；
- 绕过框架直接发 HTTP；
- 让 AI 重算水分公式、覆盖原始数值或自动作出合格/责任结论；
- 因 AI 拒绝、超时或响应无效导致整批任务失败。

应增加报告级回归测试，证明允许、拒绝、缺少密钥、非法响应四种情况下的报告均清楚且可读。

## 四、结构化明细要求

`result.json` 及模块技术 JSON 继续保持机器可读、可追溯和合同兼容，不要为了界面美观删字段或改结构。客户主要阅读 Excel 和新版 Markdown；框架会负责通用的人类视图和原始 JSON 折叠展示。

## 五、自测与通过标准

至少覆盖：

- 21 份历史水分文件及正常/偏高/偏低/区间值异常样本；
- 报告只展开异常、失败和待确认，不逐条堆积全部正常文件；
- 百分比、单位、小数位和颜色语义正确；
- AI 允许/拒绝/降级四类场景；
- Excel、Markdown、JSON 与 `result.json` 均能生成；
- 合同校验、模块测试、Ruff、`version`、`self-check` 和便携运行时通过；
- 输入文件 SHA-256 不变。

业务公式、阈值和预期结果由水分负责人签字确认，框架只验收接入兼容性。

## 六、重新交付方式

1. 同步最新 `origin/integration`；
2. 将模块全部活动版本元数据从 `1.0.0` 更新到 `1.0.1`；
3. 只修改 `modules/moisture/`；
4. 更新 `CHANGELOG.md`、报告模板、测试和脱敏证据；
5. 推送 `module/moisture`；
6. 创建或更新 `module/moisture → integration` Draft PR，不得指向 `main`，不得自行合并；
7. 通知项目负责人 PR、提交号、测试结果、人工报告对照截图和回滚提交。
