# 竹简工作台客户试用第一轮：框架问题诊断与修复报告

日期：2026-07-20

基线：BambooWorkbench v0.2.1

范围：未启用外部 AI API 的本地基础功能

## 一、责任边界

本轮只由框架方修复统一界面、文件打开、模块装载、协议、运行时和框架回归问题。模块公式、规则、统计口径、Excel 模板和业务输出正确性由对应模块负责人负责。

“框架兼容通过”不等于“模块业务输出正确”。

## 二、逐项诊断

| 编号 | 用户现象 | 精确位置与根因 | 责任方 | 处理结论 |
|---|---|---|---|---|
| FW-UI-001 | “应用到本批次”未勾选时与背景重合 | `resources/themes/bamboo.qss` 仅定义了 `QCheckBox::indicator:checked`，没有为未勾选状态设置可见边框和底色 | 框架 | 增加未勾选、悬停和勾选状态；加入带圈 `!` 及悬停说明 |
| FW-UI-002 | `product_usage` 排布拥挤；选项、勾选项难理解 | `ui/pages/confirmations_page.py` 把所有答案一律渲染成单行文本框，没有使用模块提供的 `options`；没有显示 `reason` 和 `source`；大量确认项没有滚动容器 | 框架 | 有选项时改为下拉框；显示原因与来源；增加滚动区域，禁止控件被压缩 |
| FW-UI-003 | 多个“密度”和 `expansion_ratio` 看起来完全重复 | 历史 41 份水煮数据实际返回 4 个不同文件的密度结论冲突，以及 3 个不同试件/单元格的膨胀率数值冲突。模块已经给出不同 `confirmation_id`、原因和来源，但框架只显示 `field` | 框架为主，水煮模块负责证明没有真实重复 | 框架显示中文含义、序号、原因、文件、工作表和单元格；模块负责人增加去重与唯一性自测 |
| FW-OPEN-001 | 水分、水煮 Markdown 报告无法打开 | 输出文件存在，类型为 `.md`；`ui/widgets/output_files.py` 完全依赖 Windows 默认文件关联，未关联 Markdown 时 `QDesktopServices.openUrl` 返回失败 | 框架 | 系统打开失败时使用工作台内置只读文本查看器 |
| FW-OPEN-002 | 水煮结构化业务记录无法打开 | 输出文件存在，类型为 `.json`；客户电脑没有 JSON 默认关联 | 框架 | 增加内置 JSON 查看器，并自动格式化缩进 |
| MOISTURE-OUTPUT-001 | 水分汇总表与杨总目标表差异较大 | Excel 由 `modules/moisture/src/moisture/reporting/xlsx_writer.py` 直接生成；框架只接收路径并展示，不改变工作表、字段、公式或格式。仓库当前没有可识别的“杨总目标汇总表”黄金样本 | 竹丝水分模块负责人 | 模块负责人取得并脱敏固化目标模板，完成结构、数值、公式、标色和图表对照整改 |

## 三、重复确认项的证据

在已完成的 41 份水煮历史数据草稿结果中，共有 8 项确认：

- `product_usage`：1 项，批次产品用途缺失；
- 密度结论复核：4 项，分别来自 `20260115.xlsx`、`20260121.xlsx`、`20260122.xlsx`、`20260134.xlsx`；
- 膨胀率数值冲突：3 项，分别来自 `20260119.xlsx!H36`、`20260135.xlsx!H22`、`20260135.xlsx!H36`。

因此，现有证据表明它们不是同一确认对象被重复插入，而是不同文件或试件共享同一个机器字段名。框架旧界面隐藏了差异信息。水煮模块负责人仍需对“同一来源、同一字段、同一原因”的真重复增加自动去重断言。

## 四、框架修复范围

- `ui/pages/confirmations_page.py`
- `ui/widgets/output_files.py`
- `resources/themes/bamboo.qss`
- 对应 UI 回归测试

本轮不修改 `modules/moisture/`、`modules/boiling/` 或 `modules/after_sales/` 的业务代码。

## 五、后续门禁

框架修复通过测试并进入 `integration` 后暂停。竹丝水分和水煮模块负责人按各自整改说明重新交付；售后模块本轮无新增整改项。收到模块 PR 后，框架方只执行兼容接入验收，不重新确认其业务输出正确性。

## 六、框架修复验证结果

- Ruff：通过；
- 新增确认页/文件预览定向回归：5 项通过；
- 框架全量测试：327 项通过，8 项因当前 Windows 账户无符号链接权限跳过；
- 三模块现有兼容回归：416 项通过，3 项按设计跳过售后独立 Web 服务；
- 三个真实模块合同校验：通过；
- 使用 41 份水煮历史数据的真实确认结果进行界面渲染：8 项均显示中文含义、序号、原因和来源，页面产生正常垂直滚动；
- Markdown/JSON 默认程序打开失败时：内置只读查看器正常显示，JSON 自动格式化。

以上结果只证明框架修复和现有模块接入兼容性；水分目标 Excel、水煮公式与业务判断仍由模块负责人按整改说明确认。
