## 4. 框架问题判断

水分组员提交的《请求修改(1).txt》指出“空模块测试在业务分支上会误扫到真实模块”，该责任判断合理；但不能把测试简单改成“预期水分模块已安装”，否则测试语义会随分支改变。

正确修复是：在测试内显式把真实模块根目录替换为全新的空临时目录，再验证三个缺失模块仍显示为禁用占位卡。框架修复仅修改测试隔离，不改变产品运行逻辑。定向测试、Ruff、本地全量测试（314 passed、8 个因当前 Windows 用户无符号链接权限而跳过）及 GitHub `quality` 均已通过；PR #18 已于 2026-07-19 合并。
