## 三、必须整改的问题

### AS2-01：Excel 位于仓库不允许的目录

#### 当前问题

PR #16 跟踪了：

- `modules/after_sales/samples/acceptance/input/pr16_acceptance_sample.xlsx`
- `modules/after_sales/samples/acceptance/output/after_sales_summary.xlsx`

仓库规则只允许脱敏电子表格位于模块的 `tests/fixtures/` 范围；运行生成的正式 Excel 不应提交进 Git。

#### 修改要求

1. 从 Git 删除生成产物 `samples/acceptance/output/after_sales_summary.xlsx`。
2. 如果 `pr16_acceptance_sample.xlsx` 是人工构造并已脱敏的测试输入，将它移动到 `modules/after_sales/tests/fixtures/`；否则删除并使用现有 fixture。
3. 更新 README、测试或说明中对旧路径的引用。
4. 演示证据使用 Markdown、JSON、PNG，或由 CI 临时生成，不提交生成的 Excel。

#### 达标标准

- CI 不再报告 `tracked spreadsheet outside sanitized test fixture scope`。
- `git ls-files` 中，售后模块电子表格只存在于 `modules/after_sales/tests/fixtures/`。
- 13 个案件及汇总结果不退化。
