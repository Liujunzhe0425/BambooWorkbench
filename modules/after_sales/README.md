# 售后分析模块

版本：`1.3.5`　模块标识：`after_sales`

## 功能

- 批量解析 `.xlsx` 和 `.xlsm` 售后案件；
- 识别投诉日期、客户与产品字段、问题分类、售后费用和处理状态；
- 可靠识别的完整日期与确定性费用直接采用，缺失、不完整或冲突值进入人工确认；
- 输出累计台账、费用分析、图表、Word 报告和结构化业务记录；
- 生成月度快照，并按年度已有正式月份生成累计成果；
- 通过框架托管 Provider 进行脱敏 AI 辅助，Provider 故障时安全降级。

## 入口与合同

- 任务及累计入口：`run_module.bat`
- 模块清单：`module.json`
- 模块私有 Schema：`schemas/`
- 支持扩展名：`.xlsx`、`.xlsm`

```powershell
modules\after_sales\run_module.bat self-check
modules\after_sales\run_module.bat run --job <绝对任务文件路径>
modules\after_sales\run_module.bat rollup --request <绝对请求路径> --response <绝对响应路径>
```

## 人工确认与 AI

任务年月与业务日期冲突、日期不完整、费用缺失或冲突、责任与结论需要判断时，模块返回公共确认项。售后 AI 请求由框架执行；模块不读取 API Key，也不直接联网。

AI 超时、无效响应或拒绝联网不会阻止确定性 Excel 处理。最终分类、责任和费用结论仍由有权限的业务人员确认。

## 安全边界

- 请求只包含脱敏、结构化内容；
- 输入、输出、快照和服务响应必须位于授权目录；
- 月度累计禁止联网，并复验每个快照和输出文件哈希；
- 不提交客户真实文件、日志、数据库或凭据。
