# 计算公式表

1. 售后数量：每个成功解析且纳入汇总的输入文件计 1 条；重复内容按用户本次输入的文件份数分别保留。
2. 月度费用：对该年份、月份、品牌下 `cost_included=true` 且费用已确认的记录求和。
3. 已解决数量：对明确为“已解决/已关闭”的记录计数，每个文件最多计 1 次。
4. 处理中数量：对解决状态为“处理中”的记录计数。
5. 未解决数量：对解决状态为“未解决”或仍待确认的记录计数。
6. 年度与全部统计：先按报修年份、再按月份升序排列；年份不明的记录单列“年份未注明”，不得与其他年份同月合并。

Excel 合计单元格使用工作簿公式生成，结构化明细保留每条记录的费用依据和纳入状态，便于追溯。
