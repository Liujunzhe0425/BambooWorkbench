# 人工复核与权限边界表

| 字段/结论 | 自动处理 | 必须人工确认的情况 |
| --- | --- | --- |
| 品牌 | 有明确证据时自动填写 | 多个品牌冲突；未知品牌可继续汇总但可复核 |
| 报修日期 | 提取完整年月日或保留月日 | 年份缺失、多个报修日期冲突 |
| 主原因 | 规则生成候选；必要时由统一 AI 服务辅助摘要和引用证据 | 根因缺失、文本矛盾或低置信度 |
| 投诉类型 | 规则生成性能/外观/加工/其他候选；AI只可辅助建议 | 每一份成功解析的 Excel 均必须逐项人工确认 |
| 售后费用 | 规则提取最终方案明确金额并保留证据；AI不得修改 | 每一份成功解析的 Excel 均必须逐项人工确认 |
| 责任工厂 | 规则仅提取原文；AI不得认定 | 每一份成功解析的 Excel 均必须由有权限人员确认 |
| 是否解决/关闭 | 仅在明确闭环文字时建议 | 执行状态不明、仅制定方案、仍待审批 |
| 赔偿/审批 | 仅展示原文和候选值 | 赔偿、审批、财务入账均不得由模型最终决定 |

人工复核值由 `finalize` 任务的 `confirmation_file` 写回，并重新生成最终 Excel。模块不得读取 Windows 凭据或绕过框架直接获取 API Key。
