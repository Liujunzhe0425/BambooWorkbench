# 字段与数据来源表

| 输出字段 | 优先数据来源 | 备用来源 | 缺失处理 |
| --- | --- | --- | --- |
| 客户/项目 | 客户/项目、客户、项目 | 无 | 保持空值 |
| 品牌 | 品牌字段、产品字段中的明确品牌 | 文件名中的明确品牌 | 写“未知”，不得用客户代替 |
| 报修日期 | 提出质量问题日期、报修日期、投诉日期 | 无 | 月日可保留，年份为空并复核 |
| 售后原因 | 售后负责人调查情况 | 反馈内容、方案申请明细、售后解决方案 | 保留具体现象并复核，不编造根因 |
| 问题类型 | 调查与原因文本 | 反馈、申请、方案中的关键词 | 归入“其他”并复核 |
| 企业售后成本 | 最终采用方案中企业实际承担的材料、人工、运费、返工、补发、赔偿、差旅 | 方案申请明细、调查中的对应金额 | 保持空值并复核，不以 0 元代替 |
| 内部责任扣款 | 原文明示的内部人员或部门责任扣款 | 责任落实、调查情况 | 单独保持空值或金额，不计入企业成本 |
| 外部承担金额 | 原文明示的供应商、合作方或其他外部主体承担金额 | 责任落实、解决方案 | 单独保持空值或金额，不计入企业成本 |
| 解决状态 | 关闭、结案、已完成等明确记录 | 责任落实与处理进度 | 不明确时进入人工确认 |

字段别名的机器配置位于 `rules/default_rules.yaml`，原始单元格位置保存在结构化明细的 `source_cells` 中。
