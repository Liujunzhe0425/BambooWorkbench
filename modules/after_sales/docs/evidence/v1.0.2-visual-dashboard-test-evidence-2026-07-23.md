## 3. 业务输出

在向后兼容原 Excel、Markdown 和 JSON 成果的基础上，新增：

1. 排版后的 Word 售后分析报告；
2. 品牌案件占比 Excel 图表；
3. 售后原因数量占比 Excel 图表；
4. 年度月度费用柱线图，保留 10,000 元红色预警线；
5. 年度图表总览：每个年份独立一页，上方两张三维饼图、下方一张 1—12 月柱状图。

所有新增成果读取与原汇总相同的人工复核后记录。不同年份不混算，年份缺失数据单独列示。

## 5. 人工边界与已知限制

- AI 仅辅助投诉类型、原因摘要、证据引用和复核建议。
- 售后费用、责任工厂、赔偿/责任认定和结案不能由 AI 自动批准。
- 原文未明确品牌时使用“未知”，不能用客户名称代替品牌。
- 月日缺少年份时单独进入“年份未注明”统计，不猜测年份。
- 图片和 PDF 暂不作为本模块正式输入。
