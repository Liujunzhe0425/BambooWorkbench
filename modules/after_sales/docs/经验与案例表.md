# 经验与案例表

| 场景 | 处理经验 | 自动结论边界 |
| --- | --- | --- |
| 开裂、发霉、分层 | 通常归入性能候选 | 仍以调查记录中的明确根因为准 |
| 色差、掉漆、污渍 | 通常归入外观候选 | 不据此直接认定责任方 |
| 尺寸错误、无法安装、漏加工 | 通常归入加工候选 | 设计、生产、安装责任需人工确认 |
| 多个费用方案 | 优先采用最终解决方案明确选中的金额 | 未写明最终采用方案时不得擅自取最大或最小值 |
| 费用转嫁供应商/合作方 | 标记为不纳入本公司售后费用 | 最终财务口径仍由负责人确认 |
| 只有“8月25日” | 保留月日并归入年份未注明 | 不用订单号或文件时间猜测年份 |

本表属于经验建议，不是正式客户标准或责任认定依据。
