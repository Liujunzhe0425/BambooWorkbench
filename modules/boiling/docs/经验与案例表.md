# 经验与案例表

| 案例 | 输入特征 | 预期结果 | 对应样例 |
|---|---|---|---|
| 全部正常 | 可计算、逐试件密度与密度差合格、剥离合格 | `success`，生成汇总和分析报告 | `01_all_pass.xlsx` |
| 密度异常 | 逐试件密度高于 1.3 | 密度 warning；原表冲突时待确认 | `02_density_observation.xlsx` |
| 膨胀率异常 | 家具用途，平均膨胀率10% | 红色不合格；原表冲突时待确认 | `03_expansion_observation.xlsx` |
| 剥离异常 | 原结论含“浸渍剥离检测不合格” | 保留原文，创建剥离 warning | `04_peel_fail.xlsx` |
| 复测 | 普通试件后增加“复测1”块 | 明细标为 `retest` | `05_retest.xlsx` |
| 试件数变化 | 3个试件 | 动态识别3个试件 | `06_three_samples.xlsx` |
| 空/未完成表 | 关键字段和试件缺失 | 不进入正常统计，创建 critical 异常 | `07_empty_incomplete.xlsx` |
| 原表/复算冲突 | 原表值与复算值不一致 | 同时保留两个值并确认 | `08_calculation_conflict.xlsx` |
| 真实编号布局 | `端1-1/端1-2/中1/端2-1/端2-2` 或纯数字 | 按表头和测量块识别 4/5 个试件 | 自动化测试动态构造 |
| 墙板规则缺口 | 用途为墙板，膨胀率7% | 不自动标色，生成 `expansion_review` | 自动化边界测试 |
| 41文件历史回归 | 33份五试件、7份四试件、1份空/未完成结构 | 41个文件结果、193个试件、源 SHA 不变 | 自动化测试动态构造 |

所有样例均为人工构造的脱敏数据，不含真实企业名称、人员、订单、客户路径或业务原表。
