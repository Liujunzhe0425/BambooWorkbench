# 经验与案例表

| 案例 | 输入特征 | 预期结果 | 对应样例 |
|---|---|---|---|
| 全部正常 | 字段完整，暂存范围内，剥离合格 | `success`，生成汇总和分析报告 | `01_all_pass.xlsx` |
| 密度观察 | 平均密度高于暂存最大值 | 密度 warning，注明非正式结论 | `02_density_observation.xlsx` |
| 膨胀率观察 | 家具用途，平均膨胀率10% | 膨胀率 warning | `03_expansion_observation.xlsx` |
| 剥离异常 | 原结论含“浸渍剥离检测不合格” | 保留原文，创建剥离 warning | `04_peel_fail.xlsx` |
| 复测 | 普通试件后增加“复测1”块 | 明细标为 `retest` | `05_retest.xlsx` |
| 试件数变化 | 3个试件 | 动态识别3个试件 | `06_three_samples.xlsx` |
| 空/未完成表 | 关键字段和试件缺失 | 不进入正常统计，创建 critical 异常 | `07_empty_incomplete.xlsx` |
| 原表/复算冲突 | 原表值与复算值不一致 | 同时保留两个值并确认 | `08_calculation_conflict.xlsx` |

所有样例均为人工构造的脱敏数据，不含真实企业名称、人员、订单、客户路径或业务原表。
