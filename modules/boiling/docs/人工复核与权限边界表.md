# 人工复核与权限边界表

| 场景 | 模块自动动作 | 人工动作 | 是否阻断 |
|---|---|---|---|
| 产品用途缺失 | 整批生成一次可批量应用的选项式确认项，不选择膨胀率规则 | 选择用途并决定是否批量应用 | 是 |
| 原表值与复算值冲突 | 保留两个值并指出来源 | 核对测量、公式和单位，选择可信值 | 否，但需复核 |
| 非核心元数据缺失 | 保留空值或 `/`，在汇总中提示待补 | 需要时补齐 | 否 |
| 空表/未完成/无可计算试件 | 排除正常统计并创建 critical 异常 | 补齐原表或确认模板变化 | 是 |
| 密度或膨胀率不合格 | 按 v0.1 规则输出异常、规则ID和来源单元格 | 复核测量和业务处置 | 否，由业务流程处置 |
| 墙板/栏杆 6.5%～8% 缺口 | 不自动标色，生成 `expansion_review` | 选择适用结论 | 是 |
| 缺少结构化开裂观察 | 只输出膨胀率维度结果和人工边界，不补写开裂事实 | 核对原表观察并签发结论 | 否 |
| 浸渍剥离不合格 | 原样保留检测结论 | 质量人员复核并签发结论 | 否，由业务流程处置 |
| 模板结构变化 | 无法识别时转异常 | 提供脱敏模板并更新映射 | 是 |

## 权限边界

- 模块没有独立 GUI，不弹窗、不要求业务人员直接运行脚本。
- 模块只读任务 JSON 明确列出的 `.xlsx` 输入副本，只写任务声明的 `output_dir`。
- 模块不扫描用户目录、不修改原始 Excel、不联网、不调用 AI、不创建子进程。
- 模块不保存客户阈值、不学习人工确认；“记住映射”由主框架在用户授权后管理。
- 模块输出是分析辅助材料，正式质量结论、签字和审批仍由客户业务人员负责。
