# 已知限制

- 当前支持标签抽取元数据，并兼容原有 `A2/C3/G3/C5` 固定位置；大幅模板改版仍需提供脱敏样表更新映射。
- 试件标签通过表头所在列识别，支持端/中/纯数字/样件/试件/复测编号；若表头名称和测量块同时大幅改版，仍需补充映射。
- 试件块最多向下解析20行；超过该长度或将不同指标拆散到不相邻区域的模板需要补充映射规则。
- `.xls`、`.xlsm`、CSV、PDF 和图片不在本版本支持范围内。
- 公式单元格没有保存缓存值时，模块优先使用可复算字段；不能复算且无缓存时保留为空。
- 原表没有结构化开裂观察字段时，模块不补写或推断开裂事实；膨胀率等级仅按现有数值规则输出。
- 墙板、栏杆平均膨胀率大于6.5%且小于8%的区间在 v0.1 规则中仍需人工复核，不自动标色。
- 产品用途“其他”没有自动膨胀率规则，需由人工确认适用标准。
- 跨任务增量去重由主框架负责；本模块只在同一批任务内按 SHA-256 跳过重复输入。
- 本版本只通过工作台统一服务合同请求知识库或 AI，不直接联网、不读取密钥；累计重算只复用快照中的既有建议，网络调用次数固定为 0。
- 月度快照以框架任务年月作为正式槽位，并校验业务日期冲突；无法安全归属单一月份时进入人工确认或拒绝生成快照。
- 框架负责正式月份登记、原子替换和后续月份累计重算；模块不直接维护正式月份索引。

## 仍需后续确认的边界

1. 墙板、栏杆 `>6.5% 且 <8%` 的最终颜色和合格性规则。
2. 如未来源表增加结构化开裂字段，其字段词表和展示方式需另行确认，不作为当前人工确认项。
3. 复测试件是替代原试件、追加统计，还是单独成组。
4. 浸渍剥离结论的规范词表和组合判定逻辑。
5. 大幅模板改版后的表头同义词与分散测量区域映射。
