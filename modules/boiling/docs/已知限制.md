# 已知限制

- 当前支持标签抽取元数据，并兼容原有 `A2/C3/G3/C5` 固定位置；大幅模板改版仍需提供脱敏样表更新映射。
- 试件标签需要位于前3列，名称以“样、样品、样件、试件、复测”开头并带编号；试件块内部各数据列需保持相对次序。
- 试件块最多向下解析20行；超过该长度或将不同指标拆散到不相邻区域的模板需要补充映射规则。
- `.xls`、`.xlsm`、CSV、PDF 和图片不在本版本支持范围内。
- 公式单元格没有保存缓存值时，模块优先使用可复算字段；不能复算且无缓存时保留为空。
- 密度与膨胀率阈值未获客户正式确认，只用于脱敏验收样例的异常观察，不能作为正式质量结论。
- 产品用途“其他”没有暂存膨胀率阈值，需由人工确认适用标准。
- 跨任务增量去重由主框架负责；本模块只在同一批任务内按 SHA-256 跳过重复输入。
- 本版本不发起知识库或 AI 请求，也不包含独立界面、定时任务或目录扫描功能。

## 待客户确认规则清单

1. 密度最小值、最大值、边界是否包含以及适用产品/规格范围。
2. 各产品用途的膨胀率阈值、测试时长与单位表达。
3. 复测试件是替代原试件、追加统计，还是单独成组。
4. 密度差允许值及是否需要正式自动判定。
5. 浸渍剥离结论的规范词表和组合判定逻辑。
6. 压制日期、浸胶日期与订单字段在所有历史模板中的位置变体。
