# 判定规则表

| 规则ID | 触发条件 | 当前动作 | 正式结论权限 |
|---|---|---|---|
| `BOILING-DENSITY-001` | 文件平均密度超出暂存范围 `1.1～1.3 g/cm³` | 创建 warning 观察项 | 未经客户确认，不生成正式结论 |
| `BOILING-EXPANSION-001` | 已知产品用途且平均膨胀率超出该用途暂存阈值 | 创建 warning 观察项 | 未经客户确认，不生成正式结论 |
| `BOILING-PEEL-SOURCE-001` | 原表明确写出“浸渍剥离检测不合格” | 保留原表结论并转人工复核 | 模块不替代检测人员 |
| `BOILING-CALC-CONFLICT-001` | 原表值与复算值超过允许差 | 同时保留两个值并人工确认 | 由有权限人员选择可信来源 |
| `BOILING-CONCLUSION-CONFLICT-001` | 原表合格/不合格结论与当前规则观察方向不一致 | 同时保留原表结论、规则观察和规则版本并创建复核项 | 暂存规则不得覆盖原表结论 |
| 无规则ID | 产品、规格、检测日期或试件缺失 | 排除正常统计，创建 critical 异常 | 补齐/复核后重跑 |
| 无规则ID | 产品用途缺失 | 草稿阻断型确认；正式阶段缺答案则失败 | 人工确认用途后才能选膨胀率标准 |

业务状态输出为：`正常`（信息完整且无异常）、`异常`（出现异常/观察项）、`信息不足`（关键字段缺失且未进入正常统计）、`待确认`（产品用途或冲突需要人工确认）。
