# 判定规则表

规则版本：`2026.07.18-v0.1`。

| 规则ID | 触发条件 | 自动结果 | 人工边界 |
|---|---|---|---|
| `BOILING-DENSITY-001` | 任一有效试件密度不在 `1.1～1.3 g/cm³`，或最大值减最小值大于 `0.1 g/cm³` | 密度不合格并列出试件、最小值、最大值、密度差和来源单元格 | 原表结论冲突时保留两者并确认 |
| `BOILING-EXPANSION-001` | 产品用途和平均膨胀率命中下表区间 | 输出膨胀率维度的绿色候选、蓝色合格或红色不合格 | 开裂观察缺失时不得补写；墙板/栏杆规则缺口转人工 |
| `BOILING-PEEL-SOURCE-001` | 原表明确写出“浸渍剥离检测不合格” | 保留原表结论并创建异常 | 模块不替代检测人员签发结论 |
| `BOILING-CALC-CONFLICT-001` | 原表显示值与复算值超过显示精度容差 | 同时保留原表值、显示值、公式、复算值和来源 | 由有权限人员选择可信来源 |
| `BOILING-CONCLUSION-CONFLICT-001` | 原表结论与规则复核方向不一致 | 两者均保留，创建可执行确认项 | 人工确认前不得覆盖原表 |
| `BOILING-INPUT-COMPLETENESS-001` | 空表、原表明确未完成、无可计算试件，或检测日期和检测结论同时缺失 | 信息不足，不进入正常统计 | 补齐后重跑 |

压制日期、班长、浸胶日期、订单信息等非核心元数据为空或 `/` 时只记录待补提示，不阻断密度和膨胀率统计。产品用途缺失时只创建一次可批量应用的确认项，不自行选择标准。

## 膨胀率区间

| 产品用途 | 平均膨胀率区间 | 结果 |
|---|---:|---|
| 全部用途 | `≤6.5%` | 绿色优等候选；须结合开裂观察 |
| 地板、家具 | `>6.5% 且 ≤8%` | 蓝色合格（膨胀率维度） |
| 地板、家具 | `>8%` | 红色不合格 |
| 墙板、栏杆 | `>6.5% 且 <8%` | v0.1 不自动标色，转人工复核 |
| 墙板、栏杆 | `8%～12%`（含边界） | 蓝色合格（膨胀率维度） |
| 墙板、栏杆 | `>12%` | 红色不合格 |

业务状态为：`正常`、`异常`、`信息不足`、`待确认`。任务级 `needs_confirmation` 只在结果中实际存在确认项时使用。所有输入均已完成处理且没有待确认项时使用 `success`，业务异常、信息不足和重复跳过继续由业务状态、异常列表与计数表达；只有至少一个文件成功且至少一个文件真实处理失败时才使用 `partial_success`。
