# 字段与数据来源表

| 输出字段 | 中文含义 | 优先数据来源 | 固定位置兼容回退 | 缺失处理 |
|---|---|---|---|---|
| `batch_no` | 批号/批次号 | 前30行中“批号、批次号、批次”标签右侧单元格 | `A2` | 保留为空，不阻断汇总 |
| `product` | 产品名称 | “产品名称、产品名、品名”标签右侧 | `C3` | 记录缺失并提示待补，不阻断可计算统计 |
| `specification` | 规格型号 | “规格型号、型号规格、产品规格、规格”标签右侧 | `G3` | 记录缺失并提示待补，不阻断可计算统计 |
| `pressing_date` | 压制日期 | “压制日期、压制时间”标签右侧 | 无 | 记录缺失并提示复核 |
| `team_leader` | 班长 | “压机班长、班组长、班长”标签右侧 | 无 | 记录缺失并提示复核 |
| `test_date` | 检测日期 | “检测日期、检验日期、试验日期、实验日期”标签右侧 | `C5` | 记录缺失；仅与检测结论同时缺失时视为未完成表 |
| `impregnation_date` | 浸胶日期 | “浸胶日期、浸渍日期、浸胶时间”标签右侧 | 无 | 记录缺失并提示复核 |
| `order_info` | 订单信息 | “订单信息、订单编号、订单号、订单”标签右侧 | 无 | 记录缺失并提示复核 |
| `product_usage` | 产品用途 | “产品用途、用途”标签右侧 | 无 | 生成一次批量确认；未确认前不选择膨胀率规则 |
| `samples` | 试件块 | 先定位“序号/试件、长度、宽度、密度、膨胀率”表头，再识别试件行 | 无 | 未识别可计算试件则不进入正常统计 |
| `source_conclusion` | 原表检测结论 | 含“检测结论/检验结论”的整行 | 无 | 保留为空，不自动补写 |
| `immersion_peel_result` | 浸渍剥离结果 | 从原表检测结论中提取 | 无 | 保留为空，不推断 |

## 试件块内部列约定

| 列/行 | 含义 |
|---|---|
| 表头“序号/试件”所在列 | 试件标签；支持 `端1-1`、`端1-2`、`中1`、`端2-1`、`端2-2`、纯数字和复测标签 |
| 表头“长度/宽度”所在列 | 长度、宽度，mm |
| 密度列之前的“厚度”列 | 水煮前厚度，mm；跳过“平均值”行后统计有效测点 |
| 表头“重量/质量”所在列 | 重量，g；在试件块内搜索首个有效数字 |
| 表头“密度”所在列 | 原表密度及来源单元格 |
| 密度列之后的“厚度”列 | 水煮后厚度，mm；支持不同测点行数 |
| 表头“膨胀率”所在列 | 原表膨胀率、显示精度及来源单元格 |

多工作表文件会根据字段标签、表头、试件标记和检测结论自动选择业务工作表。相邻试件标记或检测结论用于确定块边界，不要求固定七行、固定试件数或固定 A:H 区域。

字段提取只读取任务 JSON 中明确列出的输入副本，不扫描目录，也不修改原始工作簿。
