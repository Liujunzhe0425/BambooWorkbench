# 字段与数据来源表

| 输出字段 | 中文含义 | 优先数据来源 | 固定位置兼容回退 | 缺失处理 |
|---|---|---|---|---|
| `batch_no` | 批号/批次号 | 前30行中“批号、批次号、批次”标签右侧单元格 | `A2` | 保留为空，不阻断汇总 |
| `product` | 产品名称 | “产品名称、产品名、品名”标签右侧 | `C3` | 关键缺失，不进入正常统计 |
| `specification` | 规格型号 | “规格型号、产品规格、规格”标签右侧 | `G3` | 关键缺失，不进入正常统计 |
| `pressing_date` | 压制日期 | “压制日期、压制时间”标签右侧 | 无 | 记录缺失并提示复核 |
| `team_leader` | 班长 | “班组长、班长”标签右侧 | 无 | 记录缺失并提示复核 |
| `test_date` | 检测日期 | “检测日期、检验日期、试验日期、实验日期”标签右侧 | `C5` | 关键缺失，不进入正常统计 |
| `impregnation_date` | 浸胶日期 | “浸胶日期、浸渍日期、浸胶时间”标签右侧 | 无 | 记录缺失并提示复核 |
| `order_info` | 订单信息 | “订单信息、订单编号、订单号、订单”标签右侧 | 无 | 记录缺失并提示复核 |
| `product_usage` | 产品用途 | “产品用途、用途”标签右侧 | 无 | 草稿阶段人工确认；正式阶段必须回填 |
| `samples` | 试件块 | 前3列标签匹配“样、样品、样件、试件、复测+编号” | 无 | 未识别试件则不进入正常统计 |
| `source_conclusion` | 原表检测结论 | 含“检测结论/检验结论”的整行 | 无 | 保留为空，不自动补写 |
| `immersion_peel_result` | 浸渍剥离结果 | 从原表检测结论中提取 | 无 | 保留为空，不推断 |

## 试件块内部列约定

| 列/行 | 含义 |
|---|---|
| 试件标签列首行 | 试件标签，可位于A～C列 |
| 标签右侧第1列 | 长度，mm |
| 标签右侧第2列 | 宽度，mm |
| 标签右侧第3列 | 水煮前厚度，mm；支持不同测点行数 |
| 标签右侧第4列 | 重量，g；在试件块内搜索首个有效数字 |
| 标签右侧第5列 | 原表密度，g/cm³ |
| 标签右侧第6列 | 水煮后厚度，mm；支持不同测点行数 |
| 标签右侧第7列 | 原表膨胀率（小数或百分数） |

多工作表文件会根据字段标签、试件标记和检测结论自动选择最可能的业务工作表。相邻试件标记或检测结论用于确定试件块边界，不再要求固定七行。

字段提取只读取任务 JSON 中明确列出的输入副本，不扫描目录，也不修改原始工作簿。
