# 机器预期结果

每个 `*.expected.json` 与仓库 `tests/fixtures/boiling/samples/input/` 中同名脱敏工作簿一一对应，记录期望状态、处理数量、异常字段、确认字段、试件数量、复测数量和核心计算结果。

测试代码会复算核心样例；这些 JSON 便于人工验收和后续回归测试。密度与膨胀率按 `2026.07.18-v0.1` 正式规则输出文字结论、颜色等级和命中规则 ID；模块不再创建人工开裂确认项，墙板/栏杆 `6.5%～8%` 规则空档以及产品用途缺失仍须人工复核。

`monthly_rollup_gap.expected.json` 记录 v1.3.1 月度累计的缺月、同月替换、零联网、输出类型和错误拒绝预期；可执行样本由 `tests/test_monthly_rollup.py` 在临时授权目录中生成，不包含客户数据、真实路径或运行产物。
