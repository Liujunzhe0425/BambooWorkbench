# 更新记录

## 0.1.0 - 2026-07-16

- 提供符合 BambooWorkbench 合同的水煮实验模块入口。
- 支持 `version`、`self-check`、`run --job`。
- 支持批量解析、SHA-256 去重、汇总 Excel 和结构化结果。
- 支持产品用途的草稿人工确认与正式阶段回填。
- 增加脱敏测试、规则文档和业务边界说明。
- 支持按中文标签抽取压制日期、班长、浸胶日期、订单和产品用途。
- 支持变数量试件与复测试件，并复算体积、密度和膨胀率。
- 同时保留原表值与复算值，超过允许差时生成冲突异常及人工确认。
- 增加密度、膨胀率、剥离、空表等脱敏验收样例和机器预期。
- 汇总工作簿增加试件明细、规则说明与批次对比图表，并生成 Markdown 分析报告。
- 支持自动选择业务工作表、试件表起始列变化和不同测点行数。
- 增加正常、异常、信息不足、待确认四类业务状态及未纳入正常统计清单。
- 增加原表结论与规则观察冲突识别，保留两者并生成复核项。
