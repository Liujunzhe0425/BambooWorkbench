# 更新记录

## 1.0.0 - 2026-07-22 正式版基线统一

- 保留 `0.2.2` 已验收的固定试件位置值、缺失值回退和既有业务规则。
- 产品首次正式发布时，将模块清单与运行时版本统一为 `1.0.0`；该调整不改变计算、判定或输出口径。

## 0.2.2 - 2026-07-22 汇总表增加固定试件位置值

- 在 `水煮检测汇总` 的平均密度之前，按端1-1、端1-2、中1、端2-1、端2-2顺序增加密度和膨胀率共十列。
- 按试件标签提取对应采用值；位置或数值缺失时写入数值 `0`。
- 密度列使用三位小数格式，膨胀率列使用百分比格式。
- 增加固定列顺序、实际值映射和缺失值回退测试。

## 0.2.1 - 2026-07-22 汇总表展示精简

- 从 `水煮检测汇总` 工作表移除“缺失/待补字段”“命中规则ID”“密度来源单元格”“膨胀率来源单元格”“源表有效区域”五列。
- 保留复算冲突数和结论/规则冲突数，汇总表由 31 列精简为 26 列。
- 来源单元格、规则命中、缺失字段和有效区域仍保留在业务 JSON、试件明细或内部记录中，不改变公式、阈值和判定结果。
- 增加汇总表表头和列数回归测试。

## 0.2.0 - 2026-07-21 第四轮整改：确认项修复与输出契约收紧

- 修复 add_conclusion_rule_conflict 函数，增加 conclusion_cell 参数，确认项 source 现在包含结论单元格地址。
- 修复 product_usage_confirmation 的 reason 文本，明确提及"部分或全部输入文件"，并列明可用选项。
- 移除 run_job 中 individual_confirmation_id 的死代码（个体级 product_usage 确认项从未生成）；usage_answer 只依赖 batch_usage 和 batch_confirmation_id。
- Markdown 分析报告中异常和确认项现在包含来源文件和工作表信息，便于定位。
- 确认项 ID 使用基于文件内容的指纹（SHA-256[:12]），在 draft 和 finalize 间保持一致，且不同文件不会生成相同 ID。
- 新增 conclusion_cell 参数后，结论冲突确认项（C-CONCLUSION-RULE-）现在在 source 中携带 cell_or_range。
- 本批不涉及业务公式或阈值修改。

- 增加密度、膨胀率、剥离、空表等脱敏验收样例和机器预期。
- 汇总工作簿增加试件明细、规则说明与批次对比图表，并生成 Markdown 分析报告。
- 支持自动选择业务工作表、试件表起始列变化和不同测点行数。
- 增加正常、异常、信息不足、待确认四类业务状态及未纳入正常统计清单。
- 增加原表结论与规则观察冲突识别，保留两者并生成复核项。
