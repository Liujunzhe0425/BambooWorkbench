## 1.3.0 - 2026-07-26 月度累计、趋势与知识库辅助建议

- Finalize 为单一检测月份生成 `module-owned-v1` 水煮月度快照，保存最终人工值、密度、膨胀率、浸渍剥离、异常、冲突、业务记录和已有 AI/知识库建议；快照不包含绝对路径。
- 新增模块自有月度快照、累计请求、累计响应和确认学习描述 Schema，以及源码/便携统一的 `rollup --request --response` 离线入口。
- 累计渲染严格校验同模块、同年、月份升序、重复月份、目标月边界、路径和 SHA-256；允许月份缺口，并允许候选快照替换同月旧快照后重算。
- 年度累计生成完整 Excel 汇总、Excel 分析报告、Markdown 报告、图表和结构化业务记录；历史快照中已有的人工开裂确认字段和 AI 建议原样保留，累计网络调用次数固定为 0。
- 为墙板/栏杆规则缺口确认提供稳定、脱敏、结构化学习描述；当前公共确认合同尚未支持 `learning` 字段，模块同时提交框架适配请求。
- 支持把本模块生成的一个或多个“水煮检测汇总”工作簿作为趋势输入，按检测月份确定性汇总记录数、平均密度、平均膨胀率、环比变化、异常及复核数量。
- 至少存在两个月时生成独立的脱敏趋势 AI 候选，不依赖旧 `ai_enabled` 开关；只有一个月份时保持离线输出，不产生无意义授权。
- 通过工作台统一 `knowledge` 服务检索 `boiling` 知识库，并将已审核知识与 AI 建议共同展示在 Excel 和 Markdown 报告中；模块不读取密钥、不直接调用模型厂商。
- 新增“多月趋势”工作表和结构化 `trend_analysis` 业务记录；AI 拒绝、无密钥、断网、超时、错误或非法响应时，确定性趋势仍完整保留。
- 趋势仅用于发现变化线索，明确提示月份间规格构成可能不同；不修改现有公式、阈值、等级、人工确认边界或原始实验数据。
- 单次 AI 请求只发送最高优先级的 1 个候选，负载上限为 12 KiB，并收紧返回结构；未发送候选仍完整保留在离线成果中。
- 修复人工确认改变候选优先级后，Finalize 将原 Draft AI 建议误判为无效的问题；只有候选仍属于本次确定性候选且全部证据引用仍可验证时才保留建议，未知候选或伪造证据继续离线降级。
- 按中央 v1.3 合同补齐 manifest `monthly_rollup` 对象，接受 `task_name / period_year / period_month / learning_enabled`，并将内部快照移至顶层 `ModuleResult.monthly_snapshot`。
- 累计入口改用中央 `transaction_id`、完整快照引用、`configuration_identity` 和 `offline_required`，响应增加模块版本、快照 ID、记录数、成果哈希及稳定错误对象。
- 可学习的墙板/栏杆规则缺口确认直接携带公共 `ConfirmationPrompt.learning`；不再把学习描述或月度快照作为普通用户成果发布。

## 1.0.1 - 2026-07-23 客户验收第一轮整改与 AI 触发追加整改

- Draft 完成确定性解析与候选筛查后，只要存在 AI 辅助候选即生成统一 `service_requests`，不再依赖框架 Draft 固定为 `false` 的 `ai_enabled` 字段。
- 无候选时继续返回 `service_requests=[]`；Finalize 仍只读取框架提供的 `service_response_file`，不读取 API Key、不直接联网。
- 新增真实 `TaskService.create_and_start(ModuleId.BOILING, ...)` 回归，覆盖候选授权允许、拒绝离线降级、无候选不授权，并验证 AI 允许/拒绝后的确定性业务 JSON 完全一致。
- 所有输入文件均已成功处理且没有待确认项时，任务状态返回 `success`，即使报告中存在业务异常或信息不足记录。
- 密度、膨胀率、浸渍剥离、结论冲突和信息不足仍完整保留在业务状态、异常列表、Excel、Markdown 和 JSON 中。
- 只有成功文件与真实失败文件同时存在时使用 `partial_success`；重复文件单独计入 `skipped_count`，不再把业务异常或重复跳过误报为任务失败。
- 待人工确认时仍使用 `needs_confirmation`，不会因本次调整绕过人工确认。
- 复用工作台现有 AI 服务合同，可由框架选择 DeepSeek、OpenAI 兼容接口或离线模拟。
- AI 启用时仅发送脱敏、限量的规则复核摘要；不发送文件名、批号、订单、人员、日期或源单元格。
- AI 请求必须经过工作台脱敏预览和用户明确授权，模块不保存或接触 API Key。
- AI 仅生成原因解释、复核优先级和操作建议，不改变公式、阈值、自动等级、业务状态或人工确认结论。
- AI 拒绝、超时、报错、非法 JSON 或证据不匹配时自动降级为原有离线确定性报告。
- 新增 `boiling_analysis.xlsx`，并将 Markdown 按概况、结论、指标、异常、风险和下一步重新组织。
- 正常文件不再逐条占据 Markdown 主体；完整规则、稳定标识和来源仍保留在 Excel/JSON。
- 将分析图表中的“各批次平均膨胀率对比”改为“各型号规格平均膨胀率对比”，同规格按全部有效试件值汇总求平均。
- 本次不修改公式、阈值、等级判断或公共合同。
