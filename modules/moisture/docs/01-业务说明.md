# 竹丝水分模块业务说明

本模块读取竹丝水分检测工作簿，完成公式复核、统计、只读规则初筛、可选辅助证据复核，并输出 XLSX、Markdown 和 `result.json`。

模块由 BambooWorkbench 通过 `run_module.bat run --job <job.json>` 启动。正式运行只读输入，不提供 Web、用户、数据库或 Provider，也不保存跨进程隐藏状态。

draft 可能声明业务确认、knowledge request 或 AI request；finalize 使用原输入重算后应用合法协议答案。AI 与知识服务不可用时，确定性结果仍可生成。

验收目录中的工作簿全部为合成/脱敏数据，不代表任何客户、供应商或生产批次。
