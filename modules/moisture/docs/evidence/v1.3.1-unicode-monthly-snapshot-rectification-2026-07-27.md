日期：2026-07-27

## 问题与修复

真实形态的中文业务 `record_id` 原先错误复用了仅允许 ASCII 的版本号正则，
导致解析和确认均成功的合法任务在 finalize 写内部月度快照时失败。

v1.3.1 将私有快照的业务 ID 合同与版本号合同分离：

- 允许中文、内部空格和全角括号；
- ID 最长 235 字符，并在重复运行中保持原业务标识；
- 拒绝首尾空白、`/`、`\`、`..`、控制字符和重复 ID；
- Python 语义层与私有 JSON Schema 使用一致约束；
- finalize 保留脱敏 `MONTHLY_SNAPSHOT_*` 稳定错误码，不返回客户路径或异常原文。

## 完整链路

合成脱敏工作簿使用中文、空格和全角括号文件名，已通过：

```text
Registry
→ TaskService
→ run_module.bat draft
→ default_year 人工确认
→ run_module.bat finalize
→ 顶层 monthly_snapshot
→ MonthlyRollupService
→ run_module.bat rollup
→ 累计 XLSX、Markdown、业务记录 JSON
```

内部 `moisture-monthly-snapshot.json` 未登记为普通客户 outputs。
