## Request ID 稳定策略

AI request ID 只绑定以下稳定身份：

- draft root job ID；
- 模块 `moisture`；
- 服务 `ai`；
- 当前规则 SHA-256。

候选摘要不再参与 request ID。年份确认后新增的已审核经验引用可以改变 payload，但不会把
同一 draft 请求变成新请求。候选 ID、方向、字段、观测值、规则 hash、置信度和 evidence
仍在 finalize 中逐项严格校验；真正未知的 response ID 仍被拒绝并安全降级。
