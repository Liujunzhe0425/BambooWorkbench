## 3. 已实施变更

### 3.1 build_portable_runtime.ps1

- 存在且可被主框架 `scripts/build_real_module_runtimes.ps1` 调用
- 验证仓库 `.venv` 存在、Python 3.11+、PyInstaller 可用
- 使用 PyInstaller **onedir** 模式构建 `BambooMoistureModule.exe`
- 收集只读资源：schemas、rules、experience、templates、samples
- 收集元数据文件：module.json、run_module.bat、README.md、CHANGELOG.md、requirements.txt、pyproject.toml
- 目标路径：`dist/BambooWorkbench/modules/moisture/runtime/`
- 实施仓库边界检查（Assert-RepositoryPath）和 reparse point 检测
- 安全删除（Remove-SafeTree）仅清理本模块构建目录和 portable runtime
- 原子替换：`.runtime.incoming` → `runtime`，失败时从 `.runtime.previous` 回滚
- 构建后自动清理 `build/moisture-portable-runtime/`
- 缺失依赖或资源时明确报错，不自动安装全局依赖

### 3.2 run_module.bat

- 新增 `BAMBOO_MODULE_EXECUTABLE` 最高优先级
- 新增本地冻结程序自动发现：`runtime\BambooMoistureModule.exe`
- 优先级顺序：`BAMBOO_MODULE_EXECUTABLE` → 本地 EXE → `BAMBOO_MODULE_PYTHON` → `VIRTUAL_ENV` → 仓库 `.venv` → 模块 `.venv`
- 源码开发运行方式不退化
- 继续禁止裸 `python`、`py` 和系统 Python 回退
- 退出码协议不变（0/2/3/4）

### 3.3 runtime_paths.py

- `module_root()` 支持 frozen 模式：`sys.frozen` 时从 `sys._MEIPASS / "modules" / "moisture"` 解析
- 源码模式继续从 `__file__` 向上两级解析
