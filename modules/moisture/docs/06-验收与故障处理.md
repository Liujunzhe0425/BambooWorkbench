# 验收与故障处理

验收命令：

```powershell
.\.venv\Scripts\python.exe -m pytest modules\moisture\tests\acceptance -q
```

最小验收集包括正常、高值疑似、低值疑似、损坏、重复、11 样本，以及 draft/finalize、合法 AI 和 denied 示例。job 示例中的 `${...}` 必须替换为宿主生成的绝对任务路径。

单文件损坏进入文件级失败；AI denied/error/timeout/缺失或非结构化文本不破坏确定性输出。artifact 写入失败不会登记半成品，`result.json` 最后原子写入。

已知限制：不支持 incremental；不提供网络、Provider、Web、身份或数据库；暂不穷举全部 Windows reparse 组合；默认阈值未批准；红蓝仍需人工业务判断。
