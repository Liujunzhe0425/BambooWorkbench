# 输入字段与样本规则

输入为 `.xlsx`。模块识别供应商、物料类型、来料日期、检测日期、总重量，以及取样部门、初始质量、烘干质量、锡纸质量和相对含水率。

- 每个工作簿接受 1—10 个有效样本；11 个及以上使当前文件失败，不截断。
- 损坏文件只影响当前文件；`~$*.xlsx` 临时文件跳过。
- 内容 SHA-256 相同的后续文件跳过，输入读取前后会复核内容指纹。
- 正式运行不修改输入；可读且可靠的 Excel 值直接使用，真实歧义才生成 confirmation。
- artifact 必须解析后仍位于 job 指定的输出目录。

## 历史月度工作簿兼容

- 兼容标题形如“某供应方原竹丝水分检测”或“某供应方竹丝水分检测”的旧工作簿；仅在显式供应商或材料字段缺失时从标题回退提取。
- “到货时间”与“到货日期”按同一业务字段读取。
- 只有月日的历史日期优先使用模块配置中的 `default_year`；未配置时可从严格形如 `2026年4月份` 的父目录推断年份。
- 父目录存在多个冲突年份时拒绝处理，不使用当前年份或文件修改时间猜测。
- Excel 含水率与公式复核值在既有 `0.0001` 容差内视为一致，不因浮点尾数产生 confirmation。
