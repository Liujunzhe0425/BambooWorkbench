# 水分模块历史文档索引

本目录保存旧实施计划、迁移资料、已完成框架适配请求和旧版本说明，仅用于追溯。

- `architecture/`：已完成或已放弃的架构与实施方案；
- `framework-change-requests/`：已经完成、被取代或撤销的框架适配请求；
- `migration/`：旧项目资产迁移记录；
- 其他文件：早期业务说明、整改计划和协作记录。

其中“AI 候选规则生成”方案已经放弃，不属于当前功能或后续承诺。当前模块只允许业务人员
通过规则管理入口创建草稿、校验并确认发布。
