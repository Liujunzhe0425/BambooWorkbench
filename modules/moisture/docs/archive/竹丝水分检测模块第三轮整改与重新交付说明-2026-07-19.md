## 三、必须整改的问题

### MOIS3-01：缺少安装版独立运行时

#### 当前问题

当前模块没有 `modules/moisture/build_portable_runtime.ps1`。便携包只复制源码；在清空 `BAMBOO_MODULE_EXECUTABLE`、`BAMBOO_MODULE_PYTHON`、`VIRTUAL_ENV` 和系统 Python 后执行：

```powershell
dist\BambooWorkbench\modules\moisture\run_module.bat version
```

返回退出码 `4`，错误为：

```text
No approved virtual environment provides Python 3.11 or newer and required dependency jsonschema.
```

这不是水分计算错误，但会导致正式安装版无法使用水分模块。

#### 修改要求

1. 在 `modules/moisture/` 新增可重复执行的 `build_portable_runtime.ps1`。
2. 构建钩子使用仓库 `.venv` 作为构建工具，但产物必须是客户电脑可独立运行的冻结程序。
3. 将运行时安装到已生成的 `dist/BambooWorkbench/modules/moisture/` 内；不得提交 `.exe`、`runtime/`、`build/`、`dist/` 或 `.venv` 到 Git。
4. 入口 BAT 在便携目录中必须能自动发现本模块运行时；不能要求用户手工设置 `BAMBOO_MODULE_EXECUTABLE`。
5. 冻结运行时必须包含并正确定位 `schemas/`、`rules/active/`、`experience/`、`templates/` 等只读资源。
6. 保留源码开发时对可信仓库 `.venv` 的安全策略，不回退到裸系统 Python。
7. 构建脚本只能清理仓库自己的构建目录和便携包内本模块运行时目录，不能删除其他模块或用户目录。

#### 达标标准

- 在未安装 Python、未激活虚拟环境、未设置开发变量的模拟环境中：
  - `run_module.bat version` 返回 0，并包含 `0.1.0`；
  - `run_module.bat self-check` 返回 0，标准错误为空；
  - 一个脱敏样本能够通过 BAT 完成 draft/finalize 并生成合法 `result.json`、Excel 和 Markdown。
- `scripts/build_portable.ps1` 能自动调用水分构建钩子并通过新的便携模块门禁。
- 现有 `301 passed`、21/21、166 个样本及异常基线不退化。
