# BambooWorkbench（竹简工作台）

面向湖南桃花江竹材科技股份有限公司的 Windows 本地品质数据桌面工具，由"湖大智竹实践团队"开发。

## v0.2.0 — 初版：三业务模块正式接入

v0.2.0 在 v0.1.0 空框架基础上，集成了三个真实业务模块，具备完整的品质数据处理能力。

| 模块 | 功能 | 测试 |
|---|---|---|
| 竹丝水分检测 | 读取历史水分检测 Excel，统计均值，按 47%—55% 标准判定异常 | 337 passed |
| 水煮实验 | 解析水煮实验数据，判定密度/膨胀/剥离，生成统计摘要 | 37 passed |
| 售后分析 | 提取售后案件，多标签分类（性能/外观/加工），费用分析 | 40 passed |

### 业务规则

- **水分检测**：水分 < 47% 标黄（偏低），> 55% 标红（偏高），异常标注到单元格级别
- **水煮实验**：密度 < 1.0 g/cm³ 为观察项；膨胀率 > 10% 为不合格；严格规则与历史人工结论冲突时标记复核
- **售后分析**：同一案件可进入多个分类，案件总数去重计 1 次，分类合计允许大于案件总数

### 使用流程

1. 启动竹简工作台 → 选择业务模块
2. 导入 Excel → 点击"开始分析"
3. 系统自动处理并生成结果 Excel + Markdown 报告
4. 所有文件保存在本地，无需联网或登录

## 安装

下载最新 [Release](https://github.com/Liujunzhe0425/BambooWorkbench/releases) 中的 `BambooWorkbench-Setup.exe`，双击安装。

## 本地开发

要求 Python 3.12：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev,packaging]"
```
