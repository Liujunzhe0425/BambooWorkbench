# BambooWorkbench（竹简工作台）

BambooWorkbench 是面向湖南桃花江竹材科技股份有限公司的 Windows 本地品质数据工作台，由湖南大学智创未来团队开发。软件将竹丝水分检测、水煮实验和售后分析统一到一个桌面应用中，完成 Excel 导入、确定性规则计算、人工确认、月度累计、成果归档与可选 AI 辅助。

当前稳定版本：**v1.3.5**

## 产品特点

- **本地优先**：无需登录，业务文件、任务历史、知识学习和成果默认保存在安装目录。
- **确定性优先**：业务公式、客户规则、知识库和人工确认的优先级高于大模型建议。
- **三模块统一入口**：共用任务状态、确认清单、结果中心、历史数据、系统设置和更新机制。
- **月度滚动累计**：三个模块按“模块—年份—月份”独立维护正式月度结果，新月份只需导入当月资料即可生成截至当月的累计成果。
- **可追溯**：任务、输入、确认答案、规则快照、月度快照、输出文件和 SHA-256 均留有本地记录。
- **安全更新**：匿名检查本仓库正式 Release，显示下载进度，校验 SHA-256 后覆盖原目录并自动重启。

## 业务模块

| 模块 | 主要能力 | 典型输入 | 主要输出 |
|---|---|---|---|
| 竹丝水分检测 | 水分数据解析、异常筛查、规则/经验管理、月度快照与年度累计、独立 AI 报告 | 竹丝水分检测 Excel | 累计 Excel、分析报告、结构化业务记录 |
| 水煮实验 | 密度、膨胀率、浸渍剥离等指标计算，人工复核，月度快照与累计分析 | 水煮实验 Excel | 累计汇总、分析报告、图表、业务记录 |
| 售后分析 | 投诉日期和费用识别、问题分类、费用统计、框架托管 AI、年度累计 | 售后案件 Excel/XLSM | 累计台账、Word 报告、年度看板及图表 |

模块仅在信息缺失、格式冲突、规则边界或业务结论需要判断时进入人工确认。最终成果仍应由有权限的品质人员复核。

## 系统要求

- Windows 10 或 Windows 11，64 位；
- 建议至少 8 GB 内存；
- 安装目录需要具备读写权限；
- 建议安装到空间充足的非系统盘，例如 `D:\BambooWorkbench`；
- 日常离线处理不需要 Python、Office 或持续联网。

## 下载与安装

1. 打开本仓库的 [Releases](https://github.com/Liujunzhe0425/BambooWorkbench/releases)；
2. 下载最新的 `BambooWorkbench-Setup-1.3.5.exe`；
3. 双击安装包，选择安装目录；
4. 按需勾选桌面快捷方式，完成安装后启动“竹简工作台”。

覆盖安装或原目录重装会保留业务数据。不要通过删除整个安装目录的方式升级；重要升级前仍建议备份 `source` 和 `output`。

## 安装目录与数据

软件将数据保存在用户选择的安装根目录，不默认占用 C 盘业务数据空间。典型结构如下：

```text
BambooWorkbench/
├─ BambooWorkbench.exe
├─ source/
│  ├─ 竹丝水分/
│  ├─ 水煮模块/
│  └─ 售后分析/
├─ output/
│  ├─ 竹丝水分-2026年03月-20260728-103000/
│  └─ ...
├─ data/             # 数据库和本地索引
├─ tasks/            # 任务合同、确认稿和快照
├─ knowledge/        # 本地知识材料与学习证据
└─ module-data/      # 模块受控数据
```

`source` 是输入导航目录，用户仍需选择具体文件或月份文件夹。选择文件夹时只读取其第一层受支持 Excel，不递归读取更深层目录。

每个 `output` 子目录与一个任务对应，名称采用“任务名称—任务时间”。文件夹内包含该任务全部 Excel、报告、图表和框架生成的隐藏任务清单。数据库损坏时，软件可以依据任务清单恢复任务历史和月度索引。

## 基本使用流程

1. 在工作台选择业务模块；
2. 选择任务所属年份和月份，系统默认当前年月；
3. 保留系统生成的任务名称或自行修改；
4. 添加一个或多个 Excel，或选择包含 Excel 的文件夹；
5. 创建任务并等待确定性解析；
6. 如任务进入“等待人工确认”，从“待确认清单”打开并完成答案；
7. 提交后查看生成进度，完成后自动进入结果中心；
8. 在结果中心打开 Excel、Word、Markdown、图片等成果；
9. 在“历史数据”按年份和模块查看十二个月的正式结果。

确认答案会自动保存为本地草稿，关闭软件后可以继续填写。只有任务成功 finalize 并成为正式结果后，启用的学习证据才会生效。

## 月度正式结果与累计规则

- 每个模块每月只有一个“当前正式月度结果”；
- 重新运行同月任务时，创建前会提示替换影响；
- 新任务全部成功后才原子替换旧正式结果，失败或取消不会影响旧结果；
- 后续月份自动重算累计成果，但各月原始输入、人工确认和月度业务记录保持不变；
- 月份允许不连续，例如已有 1 月和 3 月时，3 月累计结果包含这两个月的数据，2 月仍显示未创建；
- 删除正式月度任务会撤销其学习贡献，并重新生成受影响的后续累计成果。

## 知识库与自学习

框架按模块隔离记录最终人工选择。与系统建议一致时强化原建议，不一致时强化用户修正；这些权重只用于以后相似情境中的建议排序，不会自动修改已批准规则、公式或阈值，也不会跳过人工确认。

用户可以查看每个模块、场景和选项的权重来源，撤销单条任务证据，重置某个学习场景，或重置当前模块的全部自学习偏好。

## AI 配置与联网边界

系统设置支持 DeepSeek、OpenAI 兼容 HTTPS 接口和离线模式。API Key 只保存在 Windows 安全凭据管理器，不写入 SQLite、任务文件、日志、安装包或 Git 仓库。

- 水分确定性汇总不依赖 AI，可单独生成 AI 辅助报告；
- 水煮 AI 只提供解释和复核建议，不改变公式、阈值或等级；
- 售后模块由框架管理 Provider，配置完成并通过连接测试后可跳过重复配置；
- Provider 超时或不可用时，确定性 Excel 处理和人工确认仍可继续；
- 软件会执行脱敏并记录本次发送的数据类别与摘要。

## 自动更新

安装版启动后异步检查本仓库最新正式 Release。发现更新后由用户确认，下载窗口显示百分比、已下载大小和总大小；下载完成后校验 GitHub Release 提供的 SHA-256，再覆盖当前安装目录并自动重启。

自动更新无需 GitHub Token。更新失败不会影响三个离线模块，详细边界见[自动更新机制](docs/release/automatic-updates.md)。

## 卸载与备份

正常卸载删除程序二进制、构建资源、缓存和普通日志，保留 `source`、`output`、数据库、任务快照、知识学习、模块数据、设置、安装实例标记和 Windows 凭据。若希望彻底清除数据，应在确认备份后手动删除安装根目录及对应 Windows 凭据。

建议定期备份：

- `source/` 原始输入；
- `output/` 正式成果；
- `data/`、`tasks/`、`knowledge/` 和 `module-data/`。
